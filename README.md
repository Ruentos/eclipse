# Éclipse

Casse-tête soleils et lunes (règles du binairo / Takuzu, avec signes = et ×).

- Remplis la grille : jamais plus de deux symboles identiques côte à côte, autant de soleils que de lunes par ligne et par colonne.
- `=` : même symbole des deux côtés ; `×` : symboles opposés. Chaque grille a une solution unique et se résout sans deviner.
- Mode **Du jour** : une grille 6×6 par jour, identique pour tous. Mode **Libre** : parties illimitées en 6×6 ou 8×8, trois niveaux.
- Indice : explique la prochaine déduction (un second appui remplit la case). Annuler : Ctrl+Z.

Jouer : double-cliquer `Éclipse.lnk` (fenêtre Edge), ou ouvrir `index.html`. Icônes : `python make_icons.py`.
